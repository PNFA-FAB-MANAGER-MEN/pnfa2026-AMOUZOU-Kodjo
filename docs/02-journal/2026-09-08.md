## Fait aujourd'hui

* Présence et appel.

* Poursuite de la conception du boîtier de notre projet.

* Définition des dimensions du boîtier :

  * Longueur : **120 mm**.
  * Largeur : **90 mm**.
  * Hauteur : **50 mm**.

* Prévision des différents emplacements sur le boîtier :

  * écran LCD sur le couvercle ;
  * trois LED sur le couvercle ;
  * interrupteur pour l'alimentation ;
  * LED d'état ;
  * port USB Type-C ;
  * grilles d'aération sur le côté.

### Impression 3D du boîtier

* Après la modélisation, nous avons procédé à l'impression 3D du boîtier.

* Nous avons ensuite effectué un test d'assemblage avec les différents composants.

* Lors du test, nous avons constaté plusieurs problèmes au niveau de la conception.

### Problèmes constatés

* L'écran LCD **ne rentrait pas correctement dans son emplacement**.

* L'emplacement prévu pour l'écran était trop petit.

* Nous avons également constaté qu'il **manquait une ouverture pour le port USB Type-C** destiné à l'alimentation.

* Après ces constatations, nous avons décidé de **reprendre la modélisation du boîtier** afin de corriger les différentes erreurs.

### Cours sur la FAO

* Nous avons également suivi un cours d'initiation à la **FAO (Fabrication Assistée par Ordinateur)**.

* Nous avons étudié les principaux **paramètres de coupe** utilisés en usinage :

  * vitesse de rotation de la broche ;
  * vitesse d'avance ;
  * profondeur de passe ;
  * largeur de passe ;
  * choix de l'outil de coupe ;
  * matériau à usiner.

### Pourquoi utiliser la FAO dans Fusion 360 ?

* La FAO permet de préparer la fabrication d'une pièce à partir de sa modélisation 3D.

* Dans **Fusion 360**, elle permet notamment de :

  * définir le brut ;
  * choisir les outils ;
  * définir les opérations d'usinage ;
  * régler les paramètres de coupe ;
  * simuler l'usinage ;
  * vérifier les éventuelles erreurs ;
  * générer le **G-code** pour une machine CNC.

## Appris

* Importance de vérifier les dimensions réelles des composants avant de réaliser une impression 3D.

* Importance de prévoir toutes les ouvertures nécessaires sur un boîtier.

* Nécessité de réaliser des tests d'assemblage après l'impression d'un prototype.

* Découverte de la **FAO** et de son rôle dans la fabrication assistée par ordinateur.

* Compréhension des principaux paramètres de coupe utilisés en usinage.

* Découverte de l'utilisation de la FAO dans **Fusion 360**.

* Compréhension du rôle du **G-code** dans la commande des machines CNC.

| ------------------------------------------------------ | ------------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------- |
